# 喝水提醒器

一个实用的喝水提醒工具，帮助您保持充足的水分摄入，培养健康的饮水习惯，避免脱水对身体健康的影响。

## 功能特点

- **可视化饮水记录**：直观的水瓶动画显示当前饮水进度
- **灵活的目标设置**：可自定义每日饮水目标（默认2000ml）
- **智能提醒功能**：根据设置的时间间隔提醒喝水
- **时间段控制**：可设置提醒的时间段，避免夜间打扰
- **多种记录方式**：提供预设水量和自定义水量输入
- **历史记录查看**：记录每次饮水的时间和量
- **周统计图表**：可视化展示一周的饮水情况
- **数据持久化**：自动保存数据，关闭页面后不会丢失

## 使用方法

1. **设置每日目标**：根据个人需求调整每日饮水目标（一般建议2000-2500ml）
2. **启用提醒**：打开提醒开关，设置提醒间隔和时间段
3. **记录饮水**：每次喝水后点击相应的水量按钮记录
4. **查看进度**：通过水瓶动画和进度百分比了解当前饮水情况
5. **查看历史**：在历史记录面板查看全天的饮水记录

### 水量建议

- 小口喝水：每次100-200ml
- 正常饮水：每次200-300ml
- 大量补水：每次500ml（运动后或大量出汗后）
- 每日总量：建议2000-2500ml（约8杯水）

## 使用场景

- **办公室工作**：长时间坐着办公容易忘记喝水，定时提醒保持水分
- **学习备考**：集中精力学习时，提醒适当休息和补水
- **健康管理**：帮助培养规律的饮水习惯，改善身体健康
- **运动健身**：运动前后及时补充水分，提高运动表现
- **疾病康复**：医生建议多喝水时，帮助跟踪每日摄入量

## 健康益处

保持充足的水分摄入对身体健康有多方面益处：

- 维持身体正常代谢功能
- 帮助肾脏过滤废物
- 保持皮肤健康和弹性
- 改善消化系统功能
- 提高注意力和大脑功能
- 调节体温
- 润滑关节

## 技术说明

本工具使用浏览器本地存储保存数据，您的饮水记录不会上传到任何服务器，保护您的隐私。提醒功能使用浏览器的通知API，在某些浏览器中可能需要授权才能显示通知。

## 注意事项

- 饮水需求因人而异，请根据自身情况调整目标
- 肾脏疾病或特殊健康状况者请遵医嘱控制饮水量
- 提醒功能在浏览器后台可能受限，保持页面打开可获得最佳效果
- 数据存储在浏览器中，清除浏览器数据会导致记录丢失
