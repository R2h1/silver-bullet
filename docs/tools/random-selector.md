# 随机选择器

一个简单易用的随机选择工具，帮助您从多个选项中做出随机选择，解决日常生活中的选择困难问题。

## 功能特点

- **多选项输入**：支持输入多个选项，每行一个选项
- **快速预设**：提供常用选项预设，一键添加
- **动画效果**：有趣的随机选择动画，增强体验感
- **多种选择模式**：支持单次选择和多次选择，可选择是否允许重复
- **结果记录**：保存选择历史，方便查看和分享
- **响应式设计**：完美适配各种设备屏幕

## 使用方法

1. 在文本框中输入您的选项，每行一个选项
2. 或者使用"快速添加常用选项"中的预设按钮
3. 根据需要调整选择设置（是否允许重复、选择次数）
4. 点击"开始选择"按钮，观看随机选择过程
5. 结果将显示在下方，您可以复制或分享选择结果

### 使用技巧

- 选项越多，随机选择越有趣
- 使用"不允许重复"模式可以确保每个选项只被选择一次
- 需要多次选择时，可以增加"选择次数"
- 点击"清空所有"可以重新开始

## 使用场景

- **饮食选择**：决定今天吃什么、去哪家餐厅
- **活动安排**：选择周末活动、聚会游戏
- **任务分配**：随机分配工作任务或家务
- **学习工具**：随机选择复习题目或学习内容
- **游戏决策**：解决游戏中的选择难题
- **颜色选择**：帮助设计师选择配色方案

## 技术说明

本工具使用纯前端JavaScript实现，所有选项数据仅在浏览器中处理，不会上传到任何服务器，保护您的隐私。

随机选择算法使用JavaScript的Math.random()函数，确保选择结果的随机性和公平性。

## 注意事项

- 建议至少输入2个选项以获得更好的随机选择体验
- 选择动画持续时间固定，无法自定义
- 分享功能需要浏览器支持Web Share API
- 选项数据不会自动保存，刷新页面后会丢失
