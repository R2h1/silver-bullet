# 数学计算器

一个功能完整的科学计算器，支持基本算术运算、科学函数、常数和计算历史记录功能。

## 功能特点

- **基本算术运算**：加、减、乘、除、百分比计算
- **科学函数**：三角函数(sin, cos, tan)、反三角函数、对数函数、指数函数、平方根等
- **常数支持**：π (圆周率) 和 e (自然常数)
- **计算历史**：自动保存计算历史，可点击历史记录重新使用
- **键盘支持**：支持使用键盘输入数字和运算符
- **响应式设计**：适配各种屏幕尺寸的设备

## 使用方法

1. 使用数字按钮或键盘输入数字
2. 选择需要的运算符或函数
3. 点击 "=" 按钮或按回车键计算结果
4. 查看计算结果和保存的计算历史
5. 点击历史记录中的任一项目可重新使用该表达式

### 键盘快捷键

- **数字 0-9**: 输入相应数字
- **运算符键**: +, -, *, /, % 对应相应运算
- **回车键**: 执行计算
- **退格键**: 删除最后一个字符
- **Esc 或 C 键**: 清除所有输入

## 支持的函数

- **三角函数**: sin, cos, tan, asin, acos, atan
- **对数函数**: ln (自然对数), log (常用对数)
- **指数函数**: exp (e的幂次), ^ (幂运算)
- **其他函数**: sqrt (平方根), abs (绝对值)
- **常数**: π (圆周率), e (自然常数)

## 使用场景

- **学生作业**：解决数学问题和验证计算结果
- **工程计算**：进行科学和工程领域的复杂计算
- **财务计算**：百分比计算和简单财务运算
- **日常使用**：快速进行各种数学运算

## 技术说明

本计算器使用纯JavaScript实现，所有计算在浏览器端完成，确保您的数据不会上传到任何服务器。计算历史记录使用浏览器的localStorage进行保存，关闭页面后仍然可以访问。

## 注意事项

- 复杂表达式可能需要使用括号明确运算顺序
- 某些数学函数(如对数)需要注意定义域限制
- 极大或极小的数值可能显示为科学计数法形式
- 计算历史记录保存在浏览器中，清除浏览器数据会丢失历史记录
