# 日常记账本

一个功能完整的日常记账工具，帮助您轻松记录和管理收支情况，分析消费习惯，实现个人财务健康管理。

## 功能特点

- **收支记录**：轻松记录收入和支出，支持多种分类和自定义备注
- **月度视图**：按月份查看收支情况，支持月份切换
- **财务概览**：实时显示总收入、总支出和结余情况
- **消费分析**：可视化图表展示消费分类占比，了解消费习惯
- **数据筛选**：按类型和分类筛选记录，快速找到需要的信息
- **数据管理**：支持数据导出、导入和清空，保障数据安全
- **本地存储**：所有数据存储在浏览器本地，保护隐私安全

## 使用方法

1. **添加记录**：在"添加记录"面板填写收支信息，包括类型、金额、分类、日期和备注
2. **查看记录**：在"交易记录"面板查看所有收支记录，支持按类型和分类筛选
3. **分析消费**：在"消费分析"面板查看收支分类占比，了解消费习惯
4. **管理数据**：使用"数据管理"功能导出、导入或清空数据

### 分类说明

- **收入分类**：工资薪水、奖金红包、投资理财、兼职外快、礼物收入、其他收入
- **支出分类**：餐饮美食、购物消费、交通出行、住房房租、水电物业、娱乐休闲、医疗健康、学习教育、通讯网络、其他支出

## 使用场景

- **个人理财**：管理个人日常收支，控制消费预算
- **家庭记账**：记录家庭共同开支，合理规划家庭财务
- **学生理财**：帮助学生培养理财意识，管理生活费
- **旅行记账**：记录旅行中的各项花费，控制旅行预算
- **项目记账**：跟踪特定项目的收入和支出情况

## 理财建议

1. **设定预算**：根据收入情况设定每月支出预算
2. **分类管理**：合理分类记录，了解资金流向
3. **定期复盘**：每月查看消费分析，调整消费习惯
4. **应急储备**：建议保留3-6个月的生活费作为应急资金
5. **理性消费**：避免冲动消费，区分"需要"和"想要"

## 技术说明

本工具使用浏览器本地存储保存数据，您的财务信息不会上传到任何服务器，完全保护您的隐私。数据以JSON格式存储，支持导出备份和导入恢复。

## 注意事项

- 定期导出数据备份，防止浏览器数据丢失
- 本工具适合日常记账，复杂财务需求请使用专业软件
- 数据仅存储在本地，更换设备或浏览器会导致数据丢失
- 建议使用现代浏览器以获得最佳体验
