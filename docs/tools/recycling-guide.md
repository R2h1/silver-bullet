## 功能特点

- **快速查询**：输入物品名称即可获取准确的分类信息
- **分类指南**：提供详细的投放要求和注意事项
- **常用分类**：一键查看四大分类的常见物品清单
- **类似物品推荐**：查询一个物品后显示类似物品的分类
- **分类知识**：学习垃圾分类的重要性和基本原则
- **响应式设计**：在手机和电脑上都能方便使用

## 使用方法

1. **搜索物品**：在搜索框中输入物品名称（如"塑料瓶"、"电池"等）
2. **查看结果**：获取物品的分类、投放指南和小贴士
3. **浏览分类**：点击分类按钮查看该类别下的所有物品
4. **学习知识**：了解垃圾分类的重要性和正确方法

### 四大分类说明

- **可回收物（♻️）**：适宜回收利用和资源化利用的生活废弃物
- **有害垃圾（⚠️）**：对人体健康或自然环境造成直接或潜在危害的废弃物
- **厨余垃圾（🍃）**：易腐垃圾，包括食材废料、剩菜剩饭等
- **其他垃圾（🗑️）**：除上述三类外的其他生活废弃物

- **教育培训**：作为垃圾分类教育的辅助工具
- **社区宣传**：在社区活动中推广垃圾分类知识
- **办公场所**：帮助办公室正确实施垃圾分类
- **公共场所**：在公共场所提供快速分类查询

## 环保意义

垃圾分类对环境保护有多方面重要意义：

- **减少污染**：正确分类可减少有害物质对环境的污染
- **资源回收**：提高可回收物的再利用率，节约资源
- **降低能耗**：回收利用比原材料生产消耗更少能源
- **减少填埋**：减少需要填埋的垃圾量，延长填埋场使用寿命
- **培养意识**：提高公众环保意识，促进可持续发展

## 分类技巧

1. **清洗干净**：可回收物应清洗干净后投放
2. **沥干水分**：厨余垃圾应沥干水分后再投放
3. **轻拿轻放**：有害垃圾应小心处理，防止破损
4. **拆解分类**：复合物品应拆解后按材质分类
5. **不确定先查询**：不确定如何分类时，先查询再投放

## 注意事项

- 垃圾分类标准可能因地区而异，请以当地规定为准
- 本工具提供通用分类指导，具体执行请遵循本地要求
- 特殊物品（如医疗废物、电子垃圾）可能需要特殊处理方式
- 定期关注本地垃圾分类政策的更新和变化
