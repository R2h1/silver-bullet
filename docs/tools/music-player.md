# 简易音乐播放器

一个美观实用的音乐播放器，支持本地音乐文件播放、播放列表管理和基本音频控制功能，让您享受纯粹的音乐体验。

## 功能特点

- **本地音乐播放**：支持播放本地音频文件，无需上传到服务器
- **美观界面**：现代化的设计，带有专辑封面显示和旋转效果
- **播放控制**：播放/暂停、上一首/下一首、进度调节
- **音量控制**：可调节音量大小，可视化音量条
- **播放模式**：支持随机播放和循环播放模式
- **播放列表管理**：添加、删除和管理音乐文件
- **进度条拖拽**：支持通过拖拽进度条快速定位播放位置
- **响应式设计**：完美适配各种设备屏幕

## 使用方法

1. **添加音乐文件**：点击"添加音乐"按钮，选择本地音频文件（支持多选）
2. **播放控制**：使用控制按钮进行播放/暂停、上一首/下一首操作
3. **进度调节**：点击或拖拽进度条跳转到指定播放位置
4. **音量调节**：点击音量条调节音量大小
5. **播放模式**：使用随机播放和循环播放按钮切换播放模式
6. **播放列表管理**：点击列表中的歌曲直接播放，点击删除按钮移除歌曲

### 支持的音频格式

- MP3
- WAV
- OGG
- AAC
- 以及其他浏览器支持的音频格式

## 使用场景

- **个人音乐欣赏**：播放本地存储的音乐文件
- **工作学习背景音乐**：提供轻松的背景音乐环境
- **演示和展示**：用于演示场合的背景音乐播放
- **离线音乐播放**：无需网络连接即可播放本地音乐
- **音乐文件管理**：管理和试听本地音乐收藏

## 技术说明

本播放器使用HTML5 Audio API实现，所有音频处理在浏览器端完成，音乐文件不会上传到任何服务器，保护您的隐私。

播放列表数据使用浏览器的localStorage进行保存，关闭页面后仍然可以恢复播放列表（但需要重新选择音乐文件）。

## 注意事项

- 音乐文件仅在当前浏览器会话中可用，刷新页面后需要重新选择文件
- 大型音乐文件加载可能需要一些时间，请耐心等待
- 某些音频格式可能在不同浏览器中有兼容性差异
- 播放列表保存的是文件元数据，不是文件本身，重新打开页面后需要重新选择文件
