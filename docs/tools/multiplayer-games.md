# 多人小游戏合集

一个集合了多款经典本地多人游戏的工具，让您和朋友可以在同一设备上享受游戏的乐趣，无需额外设备或网络连接。

## 功能特点

- **多款经典游戏**：包含井字棋、五子棋和数字炸弹等经典游戏
- **本地多人游玩**：所有游戏支持在同一设备上多人轮流操作
- **自定义玩家**：可以设置玩家名称，个性化游戏体验
- **游戏规则说明**：每个游戏都有详细的规则说明，新手也能快速上手
- **成绩记录**：记录游戏胜负，追踪玩家表现
- **响应式设计**：完美适配各种设备屏幕，移动端也能畅玩

## 游戏介绍

### 井字棋 (Tic-Tac-Toe)
经典的三连棋游戏，两名玩家轮流在3x3棋盘上放置自己的标记(❌或⭕)，率先将三个标记连成一条直线(横、竖或斜)的玩家获胜。

### 五子棋 (Gomoku)
在15x15棋盘上进行的策略性棋类游戏，两名玩家轮流放置黑色(⚫)或白色(⚪)棋子，率先将五个同色棋子连成一条直线的玩家获胜。

### 数字炸弹 (Number Bomb)
猜数字游戏，系统会在指定范围内随机选择一个数字作为"炸弹"，玩家轮流猜测数字，猜中炸弹数字的玩家出局，最后留下的玩家获胜。

## 使用方法

1. 从游戏列表中选择想要游玩的游戏
2. 设置玩家名称（可选）
3. 查看游戏规则（如需了解）
4. 开始游戏，按照提示轮流操作
5. 游戏结束后可以选择再玩一次或返回游戏列表

### 操作指南

- **井字棋/五子棋**：点击棋盘上的空位放置标记/棋子
- **数字炸弹**：输入猜测的数字，系统会提示炸弹在左侧还是右侧
- 所有游戏支持触摸操作，移动设备上也能流畅游玩

## 使用场景

- **家庭聚会**：家人团聚时的娱乐活动，适合所有年龄段
- **朋友聚会**：朋友间的轻松竞技，增进感情
- **教室活动**：教师可以使用这些游戏作为课堂活动或奖励
- **旅行途中**：长途旅行中的娱乐方式，无需网络
- **休息时间**：工作学习间隙的放松方式

## 技术说明

本工具使用纯前端JavaScript实现，所有游戏逻辑在浏览器中运行，不需要服务器支持。游戏数据仅保存在当前浏览器会话中，刷新页面后会重置。

## 注意事项

- 所有游戏需要玩家在同一设备上轮流操作
- 游戏进度不会自动保存，刷新页面后需要重新开始
- 建议在较新的浏览器中使用以获得最佳体验
- 移动设备上建议使用横屏模式以获得更好的游戏体验
